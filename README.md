# HackAlem

Telegram-бот для подбора подрядчиков для мероприятий.

Проект команды **«Багоделы»**, разработанный в рамках хакатона BAITC Hacks.

## О проекте

HackAlem помогает пользователю подобрать подходящих подрядчиков для мероприятия на основе заданных параметров.

Бот последовательно запрашивает:

* город;
* дату мероприятия;
* тип мероприятия;
* категорию подрядчика;
* бюджет;
* длительность;
* предпочитаемый язык.

После заполнения параметров система анализирует каталог и предлагает до трёх подходящих подрядчиков.

## Установка

Клонируйте репозиторий:

```bash id="it2yr4"
git clone https://github.com/BAITC-Hacks/hack-a7f18a38-team.git
cd hack-a7f18a38-team
```

Установите зависимости:

```bash id="u30nfj"
python -m pip install -r requirements.txt
```

## Настройка

Создайте файл `.env` в корневой папке проекта и добавьте токен Telegram-бота:

```text id="unawrx"
TELEGRAM_BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
```

Файл `.env` с реальным токеном не должен публиковаться в GitHub.

## Запуск

Для запуска Telegram-бота:

```bash id="sm9nfw"
python bot.py
```

Для локальной проверки алгоритма без подключения к Telegram:

```bash id="3k30da"
python bot.py --demo
```

## Использование

После запуска отправьте боту команду:

```text id="8q6tzl"
/start
```

Бот последовательно запросит параметры мероприятия и сформирует рекомендации.

Для отмены текущего подбора используется команда:

```text id="43wxh7"
/cancel
```

## Алгоритм работы

Процесс подбора состоит из нескольких этапов:

```text id="1h3l7a"
Город
  ↓
Дата мероприятия
  ↓
Тип мероприятия
  ↓
Категория подрядчика
  ↓
Бюджет
  ↓
Длительность
  ↓
Язык
  ↓
Подбор подрядчиков
```

Система учитывает параметры пользователя и данные каталога, после чего формирует список наиболее подходящих вариантов.
