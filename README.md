# HackAlem — каталог и Telegram-бот

Проект команды «Багоделы»: удобный подбор подрядчиков по базе хакатона.

## Открыть сайт

Откройте `open-site.bat` двойным щелчком или `index.html` в браузере. Сайт работает локально без установки зависимостей. Фильтры: город, формат, категория, бюджет, дата, язык и длительность. Есть поиск по имени и описанию, сортировка, полные анкеты и сброс фильтров.

Для предпросмотра по адресу http://127.0.0.1:8765:

```powershell
.\.venv\Scripts\python.exe serve_site.py
```

Этот адрес доступен только на вашем компьютере и пока программа работает. Сервер отдаёт только файлы сайта, не `.env`. Для повторного запуска можно использовать `preview-site.bat`.

## Запустить Telegram-бота

1. На новом компьютере установите Python 3.10+ и выполните `setup.bat`.
2. Сохраните токен в `.env`: `TELEGRAM_BOT_TOKEN=...`. Не публикуйте этот файл и не вставляйте токен в `.env.example`.
3. Откройте `start.bat`. В Telegram откройте своего бота и отправьте `/start`.

Основной подбор занимает пять шагов: город → формат → категория → дата → бюджет. Затем можно уточнить язык и длительность, изменить дату или бюджет. Кнопка «← Назад» возвращает на предыдущий шаг. `/cancel` отменяет подбор, `/help` показывает помощь.

Бот показывает до трёх совпадений по возрастанию начальной цены. При одинаковой цене используется ID для стабильного порядка. Категории с несколькими значениями учитываются независимо. Пустой лимит часов означает «не применимо» согласно исходному HTML, поэтому не исключает анкету по длительности.

Бот работает только пока запущен процесс и есть интернет. Не запускайте одновременно две копии с одним токеном. После перезапуска диалоги сбрасываются — отправьте `/start`.

## Данные и ограничения

В проект импортированы все 66 строк предоставленного CSV: 17 категорий, 13 синтетических профилей, 18 цен и 8 городов с флагом заполнения при подготовке данных. Имена анонимизированы, контактов нет. Все пометки сохранены и показаны в интерфейсе. Это не сервис реального бронирования.

Календарь из исходного HTML охватывает **23.09.2026–31.12.2026**. За пределами периода фильтр даты выдаёт пояснение. Внутри периода отсутствие даты в `busy_dates` означает только отсутствие занятости в учебной базе. На сайте без даты занятость не проверяется. Бот допускает все даты календаря, включая прошедшие, для воспроизводимой демонстрации датасета.

Цена `price_from_kzt` — начальная цена «от», не точная стоимость пакета. Бюджет сравнивается именно с ней. Окончательную стоимость по этой базе рассчитать нельзя.

## Обновить базу

Исходные файлы сохранены без изменений:

- `data/contractors.csv` — CSV пользователя;
- `data/original-preview.html` — исходный HTML-обзор.

После изменения CSV выполните:

```powershell
.\.venv\Scripts\python.exe import_dataset.py
```

Команда валидирует данные и обновляет `catalog.json` для бота и `catalog-data.js` для сайта. Перезапустите бота и обновите страницу. Не редактируйте сгенерированные каталоги отдельно: следующий импорт их заменит. При изменении периода календаря обновите границы в `matching.py` и интерфейсе сайта.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe bot.py --demo
```

Проверяются сохранность всех строк и флагов, одинаковые данные сайта и бота, границы календаря, несколько категорий у одной анкеты, фильтры, весь диалог, возврат назад и повторный поиск. Ожидаемые примеры относятся к исходному CSV.

## Основные файлы

- `bot.py` — Telegram-диалог; `main.py` — альтернативная точка запуска.
- `matching.py` — проверка каталога и подбор.
- `import_dataset.py` — импорт CSV.
- `index.html`, `styles.css`, `app.js`, `catalog-data.js` — сайт.
- `serve_site.py` — локальный предпросмотр.
- `.env` — только локальный токен, исключён из Git.

Ссылка на Telegram-бота в `index.html`: `https://t.me/hackaton_Bags_bot`. Если имя бота изменится, обновите обе ссылки.

## Опубликованный сайт

Публичный адрес: https://hackalem-bags-catalog.karavaevk906.chatgpt.site

Сайт размещён в Sites и доступен всем по ссылке независимо от этого компьютера. Telegram-бот по-прежнему запускается отдельно.

Идентификатор проекта сохранён в `.openai/hosting.json`. Для подготовки файлов сайта выполните `.\.venv\Scripts\python.exe build_site.py`; публичные файлы будут в `dist/`. Текущая публикация хранится в отдельном локальном репозитории `.site-publish` и отправлена в репозиторий Sites. Изменения локальных файлов не публикуются автоматически.
