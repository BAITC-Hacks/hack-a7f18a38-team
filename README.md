# HackAlem

Telegram-бот команды «Багоделы» для подбора подрядчиков мероприятий.

## Запуск на этом компьютере

1. Откройте `.env` рядом с `bot.py` и вставьте новый токен после `TELEGRAM_BOT_TOKEN=`. Опубликованный ранее токен замените через BotFather. Не отправляйте токен в чат и не публикуйте его.
2. Сохраните файл и откройте `start.bat` двойным щелчком.
3. Откройте своего бота в Telegram и отправьте `/start`.

Окно программы должно оставаться открытым. Остановка — Ctrl+C. Запускайте только одну копию бота с данным токеном.

На другом компьютере сначала установите Python 3.10+ (с опцией Add Python to PATH), затем откройте `setup.bat`. Файл `.venv` переносить не нужно: окружение создаётся заново.

Запуск из терминала в папке проекта:

```powershell
.\.venv\Scripts\python.exe bot.py
```

## Что умеет бот

Спрашивает город, дату, формат мероприятия, категорию, бюджет в тенге, длительность и язык. Выдаёт до трёх совпадений, сначала более дешёвые. Цена — за пакет целиком, длительность не должна превышать `max_hours`.

Команды: `/start` — начать заново, `/cancel` — отменить, `/skip` — пропустить длительность, `/help` — помощь. Диалоги хранятся в памяти и сбрасываются при перезапуске.

Это подбор, а не бронирование. Дата считается доступной, если её нет в списке `busy_dates`. Актуальность зависит от заполнения каталога; цену и доступность нужно подтвердить у подрядчика.

## Каталог

`catalog.json` содержит вымышленные демонстрационные карточки. Они помечены ДЕМО в ответах бота. Для реальной работы замените их проверенными данными.

Поля карточки: уникальный `id`, `name`, `city`, `category`, списки `formats` и `languages`, целые положительные `price_kzt` и `max_hours`, список занятых дат `busy_dates` в формате ГГГГ-ММ-ДД. Для реальной карточки задайте `demo: false` и строку `contact`. После изменения каталога перезапустите бота.

## Файлы

- `bot.py` — диалог и подключение к Telegram через polling.
- `matching.py` — загрузка каталога, подбор и оформление результата.
- `catalog.json` — данные подрядчиков.
- `main.py` — альтернативная точка запуска той же программы.
- `requirements.txt` — зависимости.
- `.env.example` — образец настройки; `.env` — локальный секрет, исключённый из Git.
- `setup.bat` и `start.bat` — установка и запуск на Windows.

## Проверка без Telegram и токена

```powershell
.\.venv\Scripts\python.exe bot.py --demo
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Демо и тесты подбора используют исходный учебный каталог и фиксированные даты октября 2026 года. После изменения каталога ожидаемые результаты нужно обновить.
